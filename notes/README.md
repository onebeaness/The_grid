# 논문 노트

논문 한 편당 노트 하나. 서지와 접근 경로는 [[docs/papers]]에 있다.

## 형식

각 노트는 여섯 절로 고정한다.

1. **무엇을 물었는가** — 연구 질문
2. **어떻게 측정했는가** — 표본, 데이터, 절차
3. **무엇이 나왔는가** — 결과. 수치를 포함한다
4. **우리 좌표계로 옮기면** — 그리드 설계의 어느 결정에 닿는가
5. **이 논문이 배제하는 것** — 안 되는 것으로 밝혀진 것
6. **관련 노트** — 링크

## 규약

- **본문 미확보** 표기: 게재지가 닫혀 있어 초록만 확보한 논문은 해당 절에 이 표기를 남긴다. 초록에 없는 수치를 추정해 채우지 않는다. 23편 중 10편이 이 상태다.
- 수치는 본문 표에서 직접 옮긴 것만 적는다. 계산한 값(예: 열화폭 %)은 그렇다고 표시한다.
- 5절은 "이 논문이 다루지 않은 것"이 아니라 "이 논문이 **아니라고 밝힌 것**"과 "이 논문의 범위 밖이라 근거로 쓸 수 없는 것"을 구분해 적는다.

## 미해결

- `omnimatch2025` — 제공된 서지로 논문을 특정하지 못했다. 저자명 또는 URL이 필요하다.

## 4절에 대한 단서

**`docs/taste-grid.md`(이론 본문)를 아직 받지 못한 상태에서 작성했다.** 따라서 4절 "우리 좌표계로 옮기면"은 다음을 전제로 쓰였다.

- 그리드는 도메인을 가로지르는 소수의 명명된 축을 갖는다
- 사람과 아이템이 같은 좌표계에 놓인다
- 좌표는 사용자에게 노출된다
- 두 사람의 좌표를 비교하는 표면이 존재한다

이 네 전제가 실제 이론과 다르면 4절 전체를 다시 써야 한다. 이론 본문을 받으면 대조해 갱신한다.

## 문체

`CLAUDE.md`가 저장소에 없어 기준을 확인하지 못했다. 노트 본문은 평서체(-다), 이모지 없음, 수치 우선으로 썼다. 기준 파일을 받으면 맞춘다.
