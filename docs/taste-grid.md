# 통합 절 — 논문 23편과의 대조

문헌 지도: [[papers]] · 논문별 노트 [[notes/README]] · 횡단 개념 [[concepts/README]]

23편 중 전문 확보 12편, 초록만 10편, 미해결 1편입니다. 이 절의 모든 수치는 전문에서 직접 옮긴 것이고, 초록만 확보한 논문에서 온 것은 그렇게 표시했습니다.

## A. 논문이 이미 답한 지점

우리가 실험으로 확인할 필요가 없는 것들입니다. 답이 나와 있으므로 그대로 채택하거나, 채택하지 않을 근거를 따로 대야 합니다.

### A-1. 도메인을 가로지르는 취향 축은 실재한다

[[notes/rentfrow2011ent]] — 3,000명 이상, 복수 표본·방법·지역에서 수렴. 다섯 차원(Communal, Aesthetic, Dark, Thrilling, Cerebral). 성격이 인구통계 위에 증분 설명력을 가짐. *(초록 근거)*

**함의**: 그리드가 임의의 임베딩 차원이 아니라 **이름을 가진 축**일 수 있습니다. 축의 존재 자체를 증명할 필요가 없습니다.

### A-2. 축은 입력의 함수다. "진짜 축"은 없다

같은 연구 그룹이 같은 대상을 다른 입력으로 재면 다른 축이 나옵니다.
- [[notes/rentfrow2003stomp]] 장르 **이름** → 4요인
- [[notes/rentfrow2011music]] 음악 **발췌**에 대한 정서 반응 → 5요인(MUSIC), 명시적으로 genre free

**함의**: 텍스트 설명 기반 좌표는 장르 라벨 계열에 가깝고 MUSIC 계열이 아닙니다. **축 이름을 붙일 때 이 구분을 지켜야 합니다.** → [[concepts/latent-space]] [[concepts/declared-vs-revealed]]

### A-3. 아이템 콜드스타트는 풀렸다

[[notes/rajput2023tiger]] — Sentence-T5 768차원 → RQ-VAE(잠재 32) → 3단계 residual quantization(코드북 각 256) → Semantic ID 길이 4. 테스트 아이템 5%를 학습에서 제거한 unseen 조건에서 Semantic_KNN을 모든 Recall@K에서 상회.
[[notes/li2023text]] — 아이템 ID를 완전히 제거. 6개 타깃 도메인 NDCG@10 평균 **15.83%**, MRR **15.99%** 개선.

**함의**: 신규 아이템에 상호작용 이력이 필요 없습니다. → [[concepts/text-as-coordinate]]

### A-4. 자유 텍스트만으로 콜드스타트 추천이 아이템 CF와 동률이다

[[notes/sanner2023]] — 153~160명 2단계 사용자 연구. 미시청 항목 NDCG@10:

| 방법 | 미시청 NDCG@10 |
|---|---|
| (Item) BPR-SLIM | 0.577 |
| (Item) WRMF | 0.573 |
| LLM **Language** Completion | **0.559** |
| (Item) EASE | 0.559 |
| Popularity | 0.534 |
| Random | 0.511 |

**함의**: 계정 연동 없이 자유 서술 한 문단으로 시작할 수 있습니다. [[notes/schwartz2013]](75,000명, 7억 단어, 성별 표본 외 정확도 91.9%)과 합치면 그 한 칸이 추천과 인물 파악을 동시에 합니다.

### A-5. 사용자 콜드스타트 전이의 천장은 AUC 0.69~0.86이다

| 근거 | 수치 |
|---|---|
| [[notes/man2017emcdr]] | 진짜 콜드스타트 사용자 AUC **0.6892** |
| [[notes/zhu2021tmcdr]] | 6개 태스크 AUC **0.7253~0.8589**, NDCG@10 0.2246~0.3778 |
| [[notes/zhao2020catn]] | 중첩 5%에서도 MSE 열화 4.3~9.8% |

**함의**: 전이로 채운 축을 관측된 축과 같은 확신으로 표시하면 안 됩니다. 좌표에 `source`와 `confidence`가 필요합니다. → [[concepts/cold-start]]

### A-6. 중첩 사용자는 소스 도메인의 1.3~10%이고, 곡선은 평평하다

[[notes/zhao2020catn]] — Amazon 기준 Book→Movie 4.795%, Movie→Music 9.999%, Book→Music 1.346%. 중첩을 100%에서 5%로(20분의 1) 줄여도 MSE 열화 4.3~9.8%.

**함의**: 소수의 멀티도메인 사용자로 전이 함수를 학습해도 됩니다. 동시에 **중첩을 늘려도 크게 나아지지 않습니다.** → [[concepts/overlap-scarcity]]

### A-7. 전이 품질은 도메인 쌍마다 크게 다르다

[[notes/zhang2024copd]] — 유사 쌍 NDCG@10 0.1495~0.1998, 비유사 쌍 0.0790~0.1577. 최악 비교 시 거의 절반.

**함의**: 도메인 쌍 전이 행렬이 필요하고, 칸마다 신뢰도를 따로 저장해야 합니다. → [[concepts/domain-transfer]]

### A-8. 도메인 공유/고유 표현의 완전 분리는 원리적으로 불가능하다

[[notes/du2024jicdr]] Proposition 1. 관측된 상호작용만으로는 참된 데이터 생성 과정을 볼 수 없습니다. 대신 joint identifiability(도메인 간 유일 대응)는 확립 가능합니다.

**함의**: "본질적 취향과 도메인별 습관을 분리했습니다"는 쓸 수 없고, "도메인이 달라도 같은 좌표계에서 읽습니다"는 쓸 수 있습니다.

### A-9. 사전 자기보고로 두 사람 사이의 끌림은 예측되지 않는다

[[notes/joel2017]] — 두 표본, 참가자당 **100개 넘는** 측정치, random forests.

| 분산 성분 | 사전 자기보고로 설명된 비율 |
|---|---|
| actor (누가 남을 더 원하는가) | 4~18% |
| partner (누가 더 원해지는가) | 7~27% |
| **relationship (누가 누구를 특별히)** | **예측 실패** |

relationship variance는 세 성분 중 **가장 큰** 분산원이었고, 측정 품질 문제는 저자들이 미리 배제했습니다. 다만 **사후** 측정(데이트 직후)으로는 16~29%가 설명됩니다.

**함의**: 경계는 데이터 양이 아니라 **만남 이전과 이후**입니다. → [[concepts/what-not-to-build]]

### A-10. 매력을 움직이는 것은 지각된 유사성이다

[[notes/tidwell2013]] — 실제 대면 스피드데이팅에서 지각된 유사성만 낭만적 호감을 예측. 실제 유사성은 예측하지 못함. *(초록 근거)*
[[notes/montoya2008]] — 460개 효과크기. 실제 r=.47, 지각 r=.39. 그러나 실제 유사성 효과는 상호작용이 시작되면 유의하게 감소하고 **기존 관계에서는 유의하지 않음.** *(초록 근거)*

**함의**: 그리드의 유효 구간은 **만나기 직전**입니다. 그리드는 만남을 만드는 도구이지 관계를 유지하는 도구가 아닙니다.

### A-11. 겹침은 개수가 아니라 비율이고, 중심성이 조절한다

[[notes/montoya2013]] — 240개 연구. proportion of similarity, centrality of attitudes, information salience에서 효과. **set size에서는 효과 없음.** 정보처리 관점이 강화 모형보다 잘 맞음. *(초록 근거)*
[[notes/tidwell2013]] — 구체적 특성별 유사성이 일반적 유사성보다 **훨씬 약한** 예측변수.

**함의**: 공통점 리스트 나열은 약한 형식입니다. 흔한 직관과 반대입니다. → [[concepts/centrality-weighting]]

### A-12. 취향은 이미 사람들이 쓰는 사회적 프로토콜이다

[[notes/rentfrow2006ballad]] — 초면 대화의 **최빈 주제가 음악**. 관찰자는 음악 선호만으로 합의적이고 정확한 인상을 형성했고, 사용한 단서는 대체로 타당했음. *(초록 근거)*

**함의**: 그리드는 새 행동을 만드는 것이 아니라 기존 행동에 재료를 댑니다. 그리고 "제3자 일치" 검증이 실제로 가능합니다. → [[concepts/calibration]]

### A-13. 수집하지 않아도 민감속성은 예측된다

[[notes/kosinski2013]] — Likes 58,000명 이상. 성적 지향 88%, 인종 95%, 정치 성향 85%, Openness는 표준검사 재검사 신뢰도에 근접. *(초록 근거)*
[[notes/rentfrow2003stomp]] — 음악 선호가 정치 성향·언어 IQ에 연결. *(초록 근거)*

**함의**: 좌표가 보호속성의 프록시가 되는지 측정해야 합니다. → [[concepts/leakage-audit]]

### A-14. 언어 기반 심리 추정의 타당도 검증 절차가 이미 정립돼 있다

[[notes/park2015]] — 학습 66,732명 / 검증 4,824명. 수렴·판별·제3자 일치·외부 준거·**6개월 재검사** 다섯 기준을 모두 통과. 지인보고 위에 증분 타당도. *(초록 근거)*

**함의**: 그리드 축의 검증 프로토콜을 새로 설계할 필요가 없습니다. → [[concepts/calibration]]

## B. 아무도 안 다룬 지점

문헌에 답이 없습니다. 그리드가 직접 실험해야 하고, 이 목록이 사실상 연구 로드맵입니다.

### B-1. 실제 겹침이 지각된 유사성으로 얼마나 전환되는가

**가장 중요한 공백입니다.**

[[notes/tidwell2013]]은 지각된 유사성이 예측한다고 말하고, [[notes/montoya2008]]은 실제 유사성이 상호작용 이후 무력해진다고 말합니다. 그런데 **실제 유사성을 잘 보여줬을 때 지각된 유사성이 얼마나 올라가는지**는 어느 논문도 측정하지 않았습니다.

이 전환율이 그리드의 존재 이유 전체를 결정합니다.
- 전환율 ≈ 0이면 그리드는 무의미합니다.
- 실제 겹침 없이 전환이 일어나면 그건 조작입니다.
- 둘 사이 어디인지가 제품의 가치입니다.

[[notes/montoya2013]]이 정보처리 관점을 지지한다는 것이 **전환이 가능하다는 간접 근거**이지만, 직접 측정된 적은 없습니다.

### B-2. 좌표 간 비교 가능성

추천 문헌 전체([[notes/survey2025coldstart]]가 조망하는 범위)가 **개인화된 랭킹**을 최적화합니다. 두 사용자의 좌표가 같은 척도 위에 있는지는 목적함수에 없고, NDCG·AUC·Recall 어느 것도 이를 보증하지 않습니다.

그리드는 좌표를 사람끼리 비교하는 제품입니다. **비교 가능성의 측정 방법 자체를 우리가 정의해야 합니다.** → [[concepts/latent-space]]

### B-3. 취향 좌표의 시간적 안정성

[[notes/park2015]]가 6개월 재검사 안정성을 보였지만 그건 **성격**입니다. 취향이 아닙니다.
[[notes/rentfrow2011ent]]도 [[notes/rentfrow2003stomp]]도 초록 범위에서 시간적 안정성을 다루지 않습니다.

**좌표가 6개월마다 크게 바뀐다면 그건 "취향"이 아니라 "최근 소비 요약"이고, 제품의 주장을 바꿔야 합니다.** → [[concepts/calibration]]

### B-4. 하나의 코드북으로 여러 도메인을 함께 양자화하면 어떻게 되는가

[[notes/rajput2023tiger]]는 Amazon 카테고리를 **각각 따로** 학습했습니다. 영화·음악·책을 하나의 RQ-VAE 코드북에 넣으면 무슨 일이 일어나는지 아무도 보고하지 않았습니다.

그리드의 핵심 아키텍처 질문이 정확히 이것입니다. → [[concepts/text-as-coordinate]] [[concepts/domain-transfer]]

### B-5. 텍스트 신호가 joint identifiability 조건을 완화하는가

[[notes/du2024jicdr]]의 Proposition 1 조건 (C1)은 상호작용 관측만을 전제로 합니다. 아이템 텍스트라는 추가 정보가 들어가면 조건이 완화되는지, 즉 분리 불가능성이 약해지는지 다룬 논문이 없습니다.

3번 갈래와 4번 갈래가 서로를 모른 채 진행되고 있는 지점입니다.

### B-6. 도메인 3개 이상

전이 문헌은 전부 **도메인 2개**입니다. EMCDR, CATN, TMCDR, CoPD, CIDER 모두 소스 하나 타깃 하나 또는 dual-target입니다. 그리드는 음악·영화·책·게임을 동시에 다룹니다. 3개 이상에서 무엇이 달라지는지 모릅니다.

### B-7. Semantic ID의 시간적 불안정성

코드북을 재학습하면 아이템의 Semantic ID가 바뀝니다. 좌표를 저장하고 **사용자에게 보여준 뒤** 재사용하는 제품에는 실무 리스크인데, [[notes/rajput2023tiger]]를 포함해 어느 논문도 다루지 않습니다. 연구는 한 번 학습하고 평가하면 끝나기 때문입니다.

### B-8. 합성 상호작용의 주류 편향

[[notes/huang2024llmsim]]이 LLM으로 상호작용을 시뮬레이션하고 2주 A/B로 GMV를 움직였지만, **시뮬레이션이 LLM의 사전 지식을 따라 주류 취향으로 쏠리는 문제**를 다루지 않습니다.

그리드에는 치명적입니다. 소수 취향 사용자의 좌표가 중앙으로 끌려가면 정확도 문제이자 공정성 문제가 됩니다.

### B-9. 좌표를 당사자와 타인에게 노출하는 것의 효과와 위험

연구는 예측만 하고 대상에게 알리지 않습니다. 그리드는 보여줍니다.
- 사용자가 자기 좌표에서 원치 않는 것을 읽게 될 수 있습니다.
- A의 좌표를 본 B가 A의 보호속성을 추론할 수 있다면, 우리가 추론한 것이 아니어도 우리가 경로를 제공한 것입니다.

[[notes/kosinski2013]]은 예측 가능성만 말하고 노출의 효과는 말하지 않습니다. → [[concepts/leakage-audit]]

### B-10. declared 겹침과 revealed 겹침 중 무엇이 지각된 유사성을 잘 만드는가

[[concepts/declared-vs-revealed]]에서 declared 층이 매칭 표면에 더 적절할 수 있다고 추론했지만, **추론이지 검증이 아닙니다.** 직관과 반대이므로 특히 확인이 필요합니다.

### B-11. 취향 유사성이 태도 유사성과 같은 방식으로 작동하는가

[[notes/montoya2013]]과 [[notes/montoya2008]]은 주로 **태도** 유사성을 다룹니다. 취향을 정체성 중심성이 높은 태도의 한 종류로 보는 것은 [[notes/rentfrow2006ballad]]로 뒷받침되지만 직접 검증된 적이 없습니다.

### B-12. 도메인 쌍 유사도를 사전에 추정할 수 있는가

[[notes/zhang2024copd]]는 유사/비유사 쌍을 **연구자가 손으로** 나눴습니다(Elec&Phone은 유사, Elec&Cloth는 비유사). 자동으로 추정하는 방법이 없습니다.

## C. 어긋나는 지점

> **미완.** 어긋남을 판정하려면 대조할 "기존 결정"이 필요한데, 이 파일에 이론 본문이 아직 없습니다.
>
> 아래는 **조건부 목록**입니다. 왼쪽 결정이 이론에 있으면 오른쪽 논문과 어긋납니다. 이론 본문을 받으면 해당 여부만 체크해 확정합니다.
>
> 지시대로 **기존 결정을 임의로 수정하지 않습니다.** 어긋난다는 사실만 기록합니다.

| # | 이런 결정이 있다면 | 어긋나는 근거 | 어긋남의 성격 |
|---|---|---|---|
| C-1 | 두 사람의 좌표로 **궁합 점수**를 산출한다 | [[notes/joel2017]] — 100개 넘는 사전 측정치로 relationship variance 예측 실패. 가장 큰 분산원이었고 측정 품질 문제는 배제됨 | **정면 충돌.** 데이터를 더 모아도 해결되지 않음 |
| C-2 | 취향이 맞으면 **관계가 오래간다**고 주장한다 | [[notes/montoya2008]] — 실제 유사성 효과가 기존 관계에서 유의하지 않음 | **정면 충돌** |
| C-3 | **실제 유사성 수치**(좌표 거리, 겹침 수)를 사용자에게 매칭 근거로 제시한다 | [[notes/tidwell2013]] — 실제 유사성은 대면 맥락에서 낭만적 호감을 예측하지 못함 | 계산 자체는 필요하지만 **근거로 제시하는 것**이 어긋남 |
| C-4 | **공통점 리스트**를 나열해 보여준다 (예: "공통 관심사 47개") | [[notes/montoya2013]] set size 무효, proportion 유효 / [[notes/tidwell2013]] 구체적 측정이 더 약함 | **형식의 문제.** 같은 정보를 다르게 제시하면 해결 |
| C-5 | 도메인 **공유 취향과 도메인 고유 취향을 분리해** 보여준다 | [[notes/du2024jicdr]] Proposition 1 — 관측 상호작용만으로 완전 분리 불가능 | **주장 범위의 문제.** joint identifiability로 후퇴하면 해결 |
| C-6 | **도메인 전이 기술**을 핵심 차별점으로 삼는다 | [[notes/zhu2021tmcdr]] Douban movie→music +0.8%, music→book +0.4% / [[notes/man2017emcdr]] Douban MLP 이득 0.7% | **포지셔닝의 문제.** 기술은 작동하지만 우리 도메인에서 한계이익이 작음 |
| C-7 | **중첩 사용자 확보**를 데이터 해자로 삼는다 | [[notes/zhao2020catn]] — 중첩 20분의 1로 줄여도 열화 4.3~9.8% | **경제성의 문제.** 확보 비용 대비 성능 이득이 작음 |
| C-8 | 모든 도메인 축을 **같은 신뢰도**로 표시한다 | [[notes/man2017emcdr]] AUC 0.6892 / [[notes/zhu2021tmcdr]] 0.725~0.859 / [[notes/zhang2024copd]] 도메인 쌍별 최대 2배 차이 | **정직성의 문제** |
| C-9 | 축 이름에 **MUSIC 모형**(Mellow/Unpretentious/Sophisticated/Intense/Contemporary)을 쓴다 | [[notes/rentfrow2011music]] — MUSIC은 음악 **발췌**에 대한 정서 반응에서 도출. 텍스트 설명 기반 좌표는 장르 라벨 계열 | **명명의 문제** |
| C-10 | [[notes/rentfrow2011ent]]의 다섯 축을 **소비 로그에 그대로** 적용한다 | 그 다섯 축은 **장르 자기보고**(declared)에서 도출됨. 우리 입력은 아이템 단위 소비 로그(revealed) | **입력 층위 불일치.** [[concepts/calibration]]의 시드 패널로 다리를 놓으면 해결 |
| C-11 | **합성/시뮬레이션 상호작용**을 평가에 포함한다 | [[notes/huang2024llmsim]] — 학습 신호로는 유효하나 평가 오염 시 LLM의 사전 판단을 측정하게 됨 | **방법론 오류** |
| C-12 | 민감정보를 수집하지 않으므로 **안전하다**고 기술한다 | [[notes/kosinski2013]] — 수집하지 않아도 예측됨. 성적 지향 88%, 인종 95%, 정치 85% | **정면 충돌** |
| C-13 | **궁합 성사율**을 핵심 KPI로 삼는다 | [[notes/joel2017]] — 예측 불가능한 것을 지표로 삼으면 지표가 노이즈를 쫓음 | **측정 설계의 문제** |
| C-14 | 좌표의 **재계산 주기**나 안정성에 대한 결정이 이론에 있다 | 근거 없음. B-3 참조 | **근거 부재.** 어긋남이 아니라 미검증 |

### 확정 절차

이론 본문을 받으면:
1. C-1 ~ C-14 각 행에 대해 이론에 해당 결정이 있는지만 표시합니다.
2. 있는 항목은 "어긋남 확인"으로 남기고, **수정 제안은 별도 절에 분리**해 기존 결정 본문은 건드리지 않습니다.
3. 이론에 있는데 위 목록에 없는 결정은 새 행으로 추가하고 대조합니다.
4. 목록에 있으나 이론에 없는 항목은 삭제하지 않고 "해당 없음"으로 남깁니다. 나중에 그 결정을 하려 할 때 다시 읽히도록.

## 남은 확인 사항

- **`omnimatch2025`** — 제공된 서지(OmniMatch, EDBT 2025, Amazon/Douban 콜드스타트 벤치마킹)로 논문을 특정하지 못했습니다. Crossref·arXiv·EDBT DOI 접두사·Semantic Scholar 어디에도 없고, 검색되는 OmniMatch는 전부 데이터 조인 탐색 논문입니다. 저자명이나 URL이 필요합니다. → [[notes/omnimatch2025]]
- **`kosinski2013`** — PNAS가 자동 요청을 차단합니다(OA hybrid). 브라우저로는 받을 수 있습니다. 현재 초록으로 노트를 썼습니다.
- **`hu2024said`** — WWW 2024 Companion은 Gold OA(CC BY)인데 ACM DL이 자동 요청을 차단합니다. [[concepts/text-as-coordinate]]의 파이프라인에 이 논문을 넣어뒀으나 **성능·비용 수치를 모른 채** 넣은 것이므로 본문 확인이 필요합니다.
- **STOMP 척도 문항** — [[concepts/calibration]]의 시드 패널에 필요합니다. [[notes/rentfrow2003stomp]] 논문 부록과 PsycTESTS 레코드(10.1037/t08222-000)에 있으나 아직 확보하지 못했습니다.
- **`CLAUDE.md`** — 문체 기준을 확인하지 못해 노트는 평서체·이모지 없음·수치 우선으로 작성했습니다.
