- `omnimatch2025` — 제공된 서지(OmniMatch, EDBT 2025, Amazon/Douban 콜드스타트 벤치마킹)로 논문을 특정하지 못했습니다. Crossref 제목검색·arXiv·EDBT DOI 접두사(10.48786)·Semantic Scholar 어디에도 해당 논문이 없고, 검색되는 OmniMatch는 모두 데이터 조인 탐색(joinability discovery) 논문입니다. 저자명이나 URL이 필요합니다.
