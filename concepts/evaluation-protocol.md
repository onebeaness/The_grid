# 평가 프로토콜

문헌에서 그대로 빌려올 수 있는 것과, 우리가 새로 만들어야 하는 것을 나눈다.

## 빌려오는 것

**1. 중첩 비율 스윕** — [[zhao2020catn]]
η ∈ {100%, 50%, 20%, 10%, 5%}로 중첩 사용자를 줄여가며 성능을 관찰한다. **이게 그리드의 SLA 곡선이다.** "음악만 연결한 사용자의 영화 축 신뢰도는 얼마인가"를 추측이 아니라 곡선으로 답한다. [[cold-start]]의 `confidence` 필드를 실제로 채우는 방법.

**2. 도메인 쌍 태스크 매트릭스** — [[zhu2021tmcdr]]
Amazon 7개 카테고리 + Douban 3개 도메인으로 6개 전이 태스크. 중첩 사용자의 20%를 콜드스타트로 홀드아웃. 지표는 **AUC와 NDCG@K**, 3회 시행 평균.

**3. 도메인 유사도 분할** — [[zhang2024copd]]
유사 쌍과 비유사 쌍을 나눠 따로 보고한다. 하나의 평균으로 뭉개면 NDCG@10이 0.079~0.200으로 벌어지는 사실이 사라진다.

**4. 베이스라인 집합**
EMCDR([[man2017emcdr]]), CATN([[zhao2020catn]]), TMCDR([[zhu2021tmcdr]]), CoPD([[zhang2024copd]]), CIDER([[du2024jicdr]]). 텍스트 기반 방식이 이들을 못 이기면 아키텍처를 바꿔야 한다. → [[domain-transfer]]

**5. 아이템 콜드스타트** — [[rajput2023tiger]]
테스트 아이템의 5%를 학습 분할에서 제거해 unseen으로 만든다. 누출 방지가 설계의 요점이다. 비교 대상은 동일 의미 공간의 최근접 이웃(Semantic_KNN).

**6. 구성타당도** — [[park2015]]
수렴·판별·제3자 일치·외부 준거·재검사. → [[calibration]]

## 규칙

**합성 상호작용은 학습 분할에만 넣는다.**
[[huang2024llmsim]]의 시뮬레이션이 평가셋에 섞이면 **LLM이 무엇을 그럴듯하다고 여기는지**를 측정하게 되지, 사람이 무엇을 좋아하는지를 측정하지 못한다. 그리드는 실제 취향 좌표를 판다고 주장하므로 이 오염은 제품 주장 자체를 무너뜨린다. 평가 분할은 관측된 행동만으로 구성한다.

**실험 조건을 섞어 인용하지 않는다.**
- [[zhao2020catn]] 중첩률 1.3~10%
- [[zhang2024copd]] 중첩률 100%, 테스트셋에서 콜드스타트 아이템 제외
- [[zhu2021tmcdr]] 중첩 사용자의 20% 홀드아웃

정반대 조건들이다. 숫자를 나란히 놓으면 안 된다.

**LOO + 999 네거티브 샘플링은 전체 카탈로그 랭킹이 아니다.**
[[zhang2024copd]]의 평가 방식이다. 서비스 지표로 그대로 옮길 수 없다.

## 새로 만들어야 하는 것

문헌에 없는 것들이다. 그리드의 핵심 주장이 여기 걸려 있다.

**1. 좌표 간 비교 가능성.**
추천 지표는 두 사용자의 좌표가 같은 척도 위에 있는지 전혀 보증하지 않는다. → [[latent-space]] 측정 방법을 우리가 정의해야 한다.

**2. 실제 겹침 → 지각된 유사성 전환율.**
[[tidwell2013]]도 [[montoya2008]]도 이 전환을 다루지 않는다. **그리드의 핵심 실험이 여기다.** 전환율이 0에 가까우면 그리드는 무의미하고, 실제 겹침 없이 전환이 일어나면 그건 조작이다.

**3. 제품 실험의 KPI.**
[[joel2017]]에 근거해 **궁합 성사율을 KPI로 쓰지 않는다.** 사전 자기보고 100개 이상으로도 관계 분산은 예측되지 않았다. 예측 불가능한 것을 지표로 삼으면 지표가 노이즈를 쫓는다.

대신:
- 지각된 유사성 척도의 사전-사후 변화 ([[tidwell2013]] 계열 문항)
- 대화 지속, 재접촉률
- 사용자 보고 "이 사람과 얘기할 거리가 있었다"
- 좌표 정정률 — 사용자가 좌표를 보고 고치는 비율. 정정 가능성이 [[text-as-coordinate]]의 논거였으므로 실제로 정정되는지 봐야 한다

**4. 누출 감사.**
보호속성 프로브의 AUC와 기저율을 버전마다 기록. → [[leakage-audit]]

**5. 온라인 리프트.**
[[huang2024llmsim]]이 2주 A/B로 GMV를 움직인 것이 B2B 고객사가 요구할 근거의 형태다. 오프라인 NDCG가 아니다.
