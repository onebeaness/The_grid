# 콜드스타트

문헌이 하나로 부르지만 그리드에서는 **세 개의 다른 문제**다. 난이도가 크게 다르고, 셋 중 둘은 이미 풀렸다.

## 세 갈래

**1. 아이템 콜드스타트 — 사실상 해결됐다.**

신규 아이템에 상호작용 이력이 없는 문제. 텍스트만 있으면 좌표를 얻는다.
- [[rajput2023tiger]] — Sentence-T5 768차원 → RQ-VAE → Semantic ID. 테스트 아이템 5%를 학습에서 제거한 unseen 조건에서 Semantic_KNN을 모든 Recall@K에서 상회
- [[li2023text]] — 아이템 ID를 아예 없애고 key-value 속성 텍스트만 사용. zero-shot 전이 가능
- [[hu2024said]] — 임베딩에서 텍스트를 복원하도록 강제해 의미 보존. 추론 비용을 오프라인으로 이동

그리드에서 새 영화·앨범·책이 나올 때 사용자 데이터를 기다릴 필요가 없다. **4번 갈래가 그리드에 주는 가장 큰 선물이다.**

**2. 사용자 콜드스타트(부분) — 작동하지만 천장이 낮다.**

한 도메인에는 기록이 있고 다른 도메인에는 없는 사용자. [[domain-transfer]] 참조.

천장을 숫자로 적어둔다.
| 근거 | 수치 |
|---|---|
| [[man2017emcdr]] | 진짜 콜드스타트 사용자 AUC **0.6892** (2017 SOTA) |
| [[zhu2021tmcdr]] | 6개 태스크 AUC **0.725~0.859**, NDCG@10 0.2246~0.3778 |
| [[zhao2020catn]] | 중첩 5%에서도 MSE 열화 4.3~9.8%에 그침 |

0.69~0.86이다. **"당신의 영화 취향을 알아냈습니다"라고 말할 수 있는 수준이 아니다.** 이 숫자가 UI의 신뢰도 표기 정책을 강제한다. 전이로 채운 축은 관측된 축과 같은 확신으로 보여주면 안 된다.

**3. 사용자 콜드스타트(완전) — 자유 텍스트로 푼다.**

어느 도메인에도 기록이 없는 신규 사용자. [[zhao2020catn]]도 [[zhu2021tmcdr]]도 이 경우를 다루지 않는다. 소스 도메인에는 기록이 있어야 한다.

답은 다른 데서 온다. [[sanner2023]]: 자유 서술 문단만 가진 LLM이 미시청 항목 NDCG@10 **0.559**를 낸다. 완전 지도학습된 아이템 기반 CF가 0.559~0.577이다. **사실상 동률이다.**

즉 계정 연동이 하나도 없어도 "어떤 걸 좋아하는지 한 문단 써주세요"로 시작할 수 있다. → [[text-as-coordinate]]

## 신뢰도를 좌표에 붙인다

세 갈래의 난이도가 다르므로 좌표는 단일 값이 아니라 **출처와 신뢰도를 동반해야** 한다.

```
film:  { source: "observed",    confidence: 0.91 }
music: { source: "observed",    confidence: 0.77 }
book:  { source: "transferred", confidence: 0.48, from: ["film","music"] }
game:  { source: "stated",      confidence: 0.31 }
```

`source`와 `confidence`가 제품 정직성의 최소 단위다. [[zhao2020catn]]의 η 스윕이 `confidence` 값을 실제로 채우는 방법이다. → [[evaluation-protocol]]

## 합성 데이터의 자리

[[huang2024llmsim]]은 LLM으로 상호작용을 시뮬레이션해 콜드 아이템을 워밍업한다. 2주 A/B에서 GMV를 실제로 움직였다.

**쓸 수 있는 자리**: 그리드 초기 부트스트랩. 학습 분할에만.
**쓰면 안 되는 자리**: 평가. 시뮬레이션이 평가셋에 섞이면 LLM이 무엇을 그럴듯하다고 여기는지를 측정하게 된다. → [[evaluation-protocol]]

미기록 리스크: 시뮬레이션은 LLM의 사전 지식을 따라 **주류 취향으로 쏠린다.** 소수 취향 사용자의 좌표가 중앙으로 끌려갈 수 있고, 그건 그리드에서 치명적이다.
